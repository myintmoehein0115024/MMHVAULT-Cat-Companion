# 以后与 MMHVAULT 集成时的边界

1. 该项目始终独立仓库、独立版本、独立测试，不向 MMHVAULT 页面注入财务写操作。
2. 只允许有限事件：页面已切换、用户点击宠物、宠物设置更新；禁止默认读取、记录财务明细和密码。
3. 以独立自定义元素或外部模块加载，不在 `app.html` 内塞大量3D源码。
4. 悬浮宠物不能挡住数字、按钮和付款流程，必须有关闭入口与移动端低功耗模式。
5. 验收环节：WebGL2 启动、连续使用30分钟、切换页面、不重复挂载、缩放与拖动、手机发热和功耗、断网回退、移动端 fps、屏幕阅读器和用户减少动态效果设置。
6. 正式接入前，保留 MMHVAULT 旧代码备份与一键回滚策略。
