# 黑金猫高精度 3D 角色资产规范（待制作）

该目录目前**没有电影级最终3D模型**。当前网页 `js/renderer.js` 仅提供一个实时3D临时角色用于测试行为。

目标交付：可商用的 GLB / glTF 2.0 角色模型。建议角色高度在网页中归一化为约 1.6 单位、面向局部 +Z 方向，地面在 Y=0。外观应符合已确定的黑金幼猫参考，四足自然，琥珀金眼睛，精致黑金毛色，尾部蓬松，避免玩偶关节拼接。

资产需要包含：合理拓扑、UV、PBR 基础贴图、金属粗糙度、眼角膜及透明材质（如适用）、优雅的光照表现、移动端LOD、所有骨骼权重与表情动画。以浏览器运行质量为目标，不能仅以 Blender / 离线渲染效果验收。版权或购买许可须允许商业使用和在线分发。

接入原则：使用独立 GLB 加载适配器替换测试角色，不修改 MMHVAULT 财务模块。浏览器GLB解析/动画混合适配需要在下一阶段实现，这一版尚未包含加载器，不能宣称已经能直接导入任意3D模型。
